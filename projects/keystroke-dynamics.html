Project

Keystroke Dynamics Authentication

Behavioral biometrics for user authentication

Back to Projects GitHub

Overview

This project explores keystroke dynamics as a behavioral biometric for authentication. Instead of relying only on passwords, the system analyzes timing features such as key hold and flight times to distinguish users.

Approach

I built a data pipeline to collect timing features, trained classification models, and evaluated performance under different thresholds. The focus was on reproducibility and clear evaluation metrics.

Security considerations

  • Sensitivity of behavioral data
  • False positives versus false negatives
  • Use as a supplemental factor, not a standalone control

Tools

Python, NumPy, scikit learn
