Project

Keystroke Dynamics Authentication

A Python authentication prototype that explores behavioral biometrics as an additional signal for identity verification.

Back to Projects GitHub

Overview

The system analyzes typing behavior, including hold times and flight times, to distinguish users. It is designed as a supplemental authentication factor rather than a replacement for password or multi-factor controls.

Approach

Built a data pipeline for timing-feature extraction, anomaly detection, and classification. Evaluation focused on threshold tuning, reproducibility, and the balance between false accepts and false rejects.

Security considerations

  • Behavioral data should be treated as sensitive user data.
  • Authentication thresholds have usability and security tradeoffs.
  • The technique is best used as a supplemental signal, not a standalone control.

Tools

  • Language
    Python
  • Libraries
    NumPy, scikit-learn, Matplotlib
  • Focus
    Authentication, anomaly detection, model evaluation.
