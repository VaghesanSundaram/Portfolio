CTI Claim Provenance

A controlled comparison of two pipelines for answering vulnerability-source questions with traceable supporting evidence.

RepositoryResume PDF

Question

Do explicit provenance constraints help a model bind an answer to the right frozen source evidence, and do they also improve the exact structured answer? The project keeps those outcomes separate.

Method

I built a 192-cell comparison with gpt-5.6-luna using frozen vulnerability-source questions. Each question was evaluated under a citation-prompted baseline and a constrained pipeline, then scored separately for evidence-binding and strict canonical-answer matching. The corpus includes related question families, so results are summarized as a controlled comparison rather than independent factual samples.

Observed result

Aggregate result across 96 cells per pipeline
PipelineEvidence-bindingStrict canonical-answer match
Citation-prompted baseline80 / 96 (83.3%)32 / 96 (33.3%)
Constrained pipeline83 / 96 (86.5%)25 / 96 (26.0%)

The constrained pipeline had a small gain in selecting and binding the relevant evidence, particularly on temporal questions, but it did not produce a broad accuracy gain: exact canonical-answer matching declined. The result is a tradeoff between evidence selection and answer construction, not proof that either pipeline is generally more accurate.

Limits

This is one model, one frozen corpus, and one run per cell. Question families share source dependencies, so the cells are not independent observations. The reported percentages should not be treated as significance-tested or causal estimates.
