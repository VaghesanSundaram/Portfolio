Project

Static SAST Triage Agent Benchmark

A reproducible benchmark for model-assisted SAST alert triage, built from RealVuln scanner alerts, source evidence, schema validation, and deterministic scoring.

Back to Projects GitHub Public Writeup

Overview

The project packages 296 public RealVuln scanner-alert cases with copied source evidence for true-positive and false-positive triage. Cases are imported from scanner JSON rather than hand-written examples, and each active case records dataset provenance, upstream source repository metadata, scanner output source, and the deterministic matching rule used for expected verdicts.

Methodology

The benchmark builds a model-facing case bundle, validates schemas, runs hosted-model responses through a fixed response contract, and scores results with deterministic scripts. The release includes raw scanner outputs from Semgrep, Snyk, and SonarQube; review state for unmatched false positives; baseline runs; hosted-model outputs; score summaries; and run metadata.

Results and limitations

The checked-in results compare multiple OpenAI and Anthropic models on verdict accuracy, TP accuracy, FP accuracy, CWE accuracy, and severity accuracy. The README reports Claude Sonnet leading overall verdict accuracy in the included runs, while Claude Opus is strongest on the false-positive slice. The claim is intentionally bounded: this is a reproducible RealVuln public-data triage benchmark, not a broad production SAST benchmark or unseen-code generalization result.

Benchmark Facts

  • Cases
    296 RealVuln scanner alerts.
  • Verdicts
    211 true positives and 85 false positives.
  • Scanners
    Semgrep, Snyk, and SonarQube.
  • Artifacts
    Schemas, runners, score summaries, run metadata, and public writeup.
