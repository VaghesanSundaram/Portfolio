Project

Prophet

Decentralized prediction markets with AI assisted forecasting

Back to Projects GitHub

Overview

Prophet is a decentralized prediction market prototype built during Fall HackPrinceton 2025. Users create markets, place trades via smart contracts, and view aggregated forecasts.

Approach

The project required coordinating smart contracts, backend services, and a front end under tight time constraints. Design decisions balanced feasibility, security assumptions, and demo reliability.

Security considerations

  • Threat modeling for user submitted data
  • Trust boundaries between on chain and off chain components
  • Failure modes under incomplete or adversarial input

Tools

Solana, backend services, frontend stack
